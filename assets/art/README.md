# The Moves Deck — Art Assets

**Style decision:** the deck's identity is the workbench — honest craft, warm
tungsten light, copper and oiled steel. Deliberately hands-on where the
Judgement Deck is a desk and the Governance Deck is a boardroom. Every prompt
starts with this canonical prefix:

```
warm craftsman photograph, a worn wooden workbench at night under a single
tungsten lamp, copper and oiled steel hand tools, deep amber palette, dramatic
shadows, soft film grain, honest working atmosphere, generous dark negative
space
```

Every prompt ends with: `no text, no letters, no words`

Regenerate with `limn generate -s <size> -o <path> "<prefix>, <subject>, no
text, no letters, no words"` (default SwarmUI, juggernautXL_v9). Sidecars
(.png.json) record the exact prompts.
