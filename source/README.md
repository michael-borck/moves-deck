# The Moves Deck — source note

Distilled from the Copilot in Practice courses (commercial white-label and
Curtin editions, Curtin Executive Education, Dr Michael Borck):

- `curtin/exec-ed/copilot-in-practice/` — the carry pattern, context guide,
  prompt library (22 blocks), take-home checklist, after-course pack (critique
  toolkit, prompt-to-workflow, chaining, managing context, agents with
  oversight), responsible use ("prompt, process, protect").
- `curtin/exec-ed/copilot-in-practice-curtin/` — the trust tool framing, the
  Catch-it exercise (seeded drafts, seven planted errors, check without the
  tool), the closing habits.

**De-vendored by design.** The moves are assistant-agnostic; app names and
licence mechanics from the source were generalised. The "Where it lives"
section (cards 31–36) is the family index: high-level, durable facts about
where standing context, projects and memory live on each assistant. Those six
cards are the only content not anchored in course material — review them
against each product's current behaviour before print.

Voice: short declaratives, present tense, dry wit. "You are the orchestrator."
