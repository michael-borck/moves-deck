# The Moves Deck

<p align="center">
  <img src="assets/art/banner.png" alt="The Moves Deck" width="720">
</p>

Thirty-six moves for working with any AI assistant at work. Distilled from the
Copilot in Practice courses and deliberately de-vendored — the family parent:
the same moves, whatever the badge on the app. Free product: no gate, no capture.

**Live:** https://michael-borck.github.io/moves-deck/

**You are the orchestrator.**

## The design

One organic size: 36 cards — Orchestrate (6), Brief (6), Catch It (6),
Workflow (6), Protect (3), Commit (3), Where It Lives (6). The final section is
the family index: one card per assistant (Copilot, ChatGPT, Claude, Gemini,
NotebookLM) on where standing context, projects and memory live. New family
members are new cards in that section, not new decks.

## deck/

| File | What it is |
|---|---|
| `moves-deck-36-cards.md` | The deck, markdown. |
| `moves-deck-36-print.html` | Print & cut. 6 A4 pages, 8 cards per sheet, cover card first. |
| `moves-deck-guide.html` | One-page diagnostic. |
| `moves-deck-desk-card.html` | Every card, every line — one A4 pin-up. |
| `moves-deck-36-art.html` | Art edition for the boxed print run: portrait cards, tinted category vignettes. |
| `fonts/` | Domine, Funnel Sans, Nanum Gothic Coding (SIL OFL). |

Art: `assets/art/` holds the workbench-brass identity (warm craftsman workbench at night, copper and oiled steel), generated with limn — prompts and sidecars in `assets/art/README.md`. Art edition included.
