# The Moves Deck

Thirty-six moves for working with any AI assistant at work. Distilled from the
Copilot in Practice courses and deliberately de-vendored — the family parent:
the same moves, whatever the badge on the app. Free product: no gate, no capture.

**Live:** https://michael-borck.github.io/moves-deck/

**You are the orchestrator.**

## The design

One organic size: 36 cards — Orchestrate (6), Brief (6), Catch It (6),
Workflow (6), Protect (3), Commit (3), Where It Lives (6). The final section is
the family index: one card per assistant (Copilot, ChatGPT, Claude, Gemini,
NotebookLM) on where standing context, projects and memory live. New family
members are new cards in that section, not new decks.
